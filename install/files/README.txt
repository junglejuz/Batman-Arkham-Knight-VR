Files the installer copies into the game folder on top of the mod itself.

                    file is never overwritten). Change them in the in-headset panel (F8, or hold both sticks).
nvngx_dlss.dll      NVIDIA DLSS 310.9.1, unchanged, installed as akn
vngx_dlss.dll. NVIDIA DLSS is
                    NVIDIA's; see the README's credits.
