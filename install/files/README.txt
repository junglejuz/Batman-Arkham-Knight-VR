Files the installer copies over the 3D fix, so every install gets the setup the mod was tested with.

d3d11.dll, nvapi64.dll  geo-11 version 0.7.11, unchanged, from
                        https://helixmod.blogspot.com/2022/06/announcing-new-geo-11-3d-driver.html
d3dxdm.ini              geo-11's settings file, set up for Batman: Arkham Knight in VR.

The fix's own files (shader fixes, d3dx.ini) are not included here: they are the fix author's,
for personal use, so each player downloads them. The installer edits d3dx.ini in place.
